# Zito Media

A communications and internet service provider serving select communities with residential internet,
whole-home WiFi, TV, voice, mobile, small business and commercial connectivity. Headquartered in
Coudersport, Pennsylvania. [zitomedia.net](https://zitomedia.net)

## Building software for Zito

This organization holds the source code for software built for Zito Media, by Zito staff and
contractors. Repositories are private, and your Zito contact requests access for you per repository.

Read the [contributing policy](https://github.com/zitomedia-corp/.github/blob/main/CONTRIBUTING.md)
before your first commit: access, branches, commit messages, AI coding tools and secrets.

# .github

Organization-wide defaults for `zitomedia-corp`.

- [development-policy.md](development-policy.md) is the policy for everyone working in the organization.
- [pull_request_template.md](pull_request_template.md) applies to every repository that has none of its own.
- [profile/README.md](profile/README.md) is the organization's public front page.
- [repositories-and-access.md](repositories-and-access.md) is for organization owners: creating repositories and giving access.
